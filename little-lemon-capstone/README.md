# Little Lemon React Native Capstone

A React Native restaurant menu app built with Expo.

## Features
- First-launch onboarding with name and email validation
- Home screen with header, restaurant hero, search, selectable categories and menu list
- Profile screen populated from onboarding
- Profile edits saved using AsyncStorage
- Logout clears the saved profile and returns to onboarding
- Native stack navigation with back navigation

## Requirements
- Node.js LTS
- Git
- Expo Go on a compatible phone, or an Android/iOS simulator

## Run locally
```bash
npm install
npx expo start
```
Scan the QR code with Expo Go, or press `a` for Android emulator / `i` for iOS simulator where available.
